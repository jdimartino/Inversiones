# Inversiones

PWA para seguimiento de inversiones en criptomonedas. React + TypeScript + Tailwind CSS + Firebase.

## Iniciar localmente

```bash
./dev.sh
```

Instala las dependencias automáticamente (si hace falta) y levanta el servidor. La app abre en [http://localhost:3000](http://localhost:3000).

> La primera ejecución tarda un poco más porque descarga los paquetes. Las siguientes son instantáneas.

## Otros comandos

| Comando | Descripción |
|---|---|
| `npm start` | Servidor de desarrollo local |
| `npm run build` | Build de producción |
| `npm run deploy` | Deploy a Firebase Hosting (`micriptoapp`) |
